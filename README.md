# Festora

Premium event and fest management, rebranded from the authorised Mehfil source project.

## Current build

- Preserves the original single-page application workflows and API action contract.
- Rebrands the product UI as Festora.
- Adds the Festora geometric F monogram and a premium teal, warm-neutral and brass visual system.
- Keeps the existing Google Apps Script backend endpoint unchanged for compatibility.

## Important integration note

The frontend currently talks to the original Google Apps Script deployment and its Google Sheet data store. That connection is intentionally retained so existing authentication, events and records are not silently migrated or lost. Before a public launch, confirm backend ownership/access and update the support Instagram URL currently retained from the source project.

## Run

This is a static single-page app. Open `index.html` locally or deploy the repository as a static site (for example, GitHub Pages or Vercel).

## Source and permission

The source was provided with permission from its original creator. Festora is maintained in this separate repository; the original repository is not modified.
